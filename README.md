# astana-ai-walk
# AI-помощник по прогулкам в Астане

Веб-приложение на Python и Streamlit, которое помогает подбирать места для отдыха, работы и прогулок в Астане. Проект создан командой Bloody kik для хакатона (трек AI MODELS FOR SMART CITY).

## Как это работает

1. Запрос пользователя: Вы вводите текстовый запрос или выбираете готовый вариант.
2. Поиск мест: Приложение ищет подходящие заведения в Астане через API 2ГИС.
3. ИИ-анализ: Google Gemini анализирует найденные варианты и выдает персональную рекомендацию.
4. Отказоустойчивость: Если API Gemini не отвечает или выдает таймаут (DeadlineExceeded), приложение выводит списки найденных мест из 2ГИС без ошибки.
5. Карта: Все найденные локации отображаются на интерактивной карте с радиусом поиска.

## Стек технологий

* Python 3.10+
* Streamlit — интерфейс приложения
* Folium / streamlit-folium — интерактивная карта
* Google Gemini API — обработка запросов и рекомендации
* 2GIS API — геоданные и поиск заведений в Астане

## Структура проекта

* app.py — главный файл интерфейса и визуализации.
* src/rag_2gis_engine.py — логика работы с API 2ГИС и генерации ответов Gemini.
* data/ — локальные данные и вспомогательные скрипты.
* requirements.txt — список необходимых библиотек Python.
* .gitignore — исключение кэша и служебных файлов из репозитория.

## Инструкция по запуску

1. Клонировать репозиторий:
git clone https://github.com/Urge-12345678910/astana-ai-walk.git
cd astana-ai-walk

2. Установить зависимости:
pip install -r requirements.txt

3. Запустить приложение:
streamlit run app.py

4. Открыть страницу приложения в браузере и ввести API-ключи Gemini и 2ГИС в боковой панели.
